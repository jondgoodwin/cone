Logging and Tracing

Note: Not built: sinks (a buffered binary file, Event Tracing for Windows, text on the console) are packages of their own, still to come, as are the packages' own instrumentation, metrics, and tools that read what a sink wrote. The actors package does not yet emit through trace or register its context.

The trace package is the one facade a package logs and traces through. A package that does work worth seeing declares its kinds of event once, and emits them where the work happens; while nothing wants an event, emitting it costs one load and a compare, and its arguments are never evaluated. A program decides what is wanted: it installs a sink, which records events somewhere, and says which targets it wants at which level, in code or from the CONE_TRACE environment variable, with no rebuild. Logging and tracing are one pipeline: a log message is an event with a level and a text. The package imports only core; its source's header comment is the full account.

An example

A package that fetches things declares three kinds, and a program prints what it is given:

mod fetcher;
import stdio use *;
import trace use Level, Kind1, Kind2, Nanos;

// The kinds a package declares: once, as globals, made in its init
let fetched: Kind2[u64, Nanos];
let refused: Kind1[i64];
let request: Kind1[&str];

fn @initpure init() {
  fetched = Kind2[u64, Nanos].make("fetched", "fetcher", Level.Debug, "bytes", "took");
  refused = Kind1[i64].make("refused", "fetcher", Level.Warn, "status");
  request = Kind1[&str].make("request", "fetcher", Level.Info, "url");
}

fn fetch(url: &str, status: i64) {
  let span = request.begin(url);
  if status != 200 {
    refused.log(status, (trace.Message() <- "the server said ", status));
  } else {
    fetched.emit(5120u64, Nanos(830000i64));
  }
  request.end(span);
}

// A sink that prints each event as a line
struct Console is trace.Sink {
  pub min: Level;

  pub fn enabled(self: &, k: &trace.Info) bool {k.level.rank() <= min.rank()}

  pub fn record(self: &, e: &trace.Event) {
    print <- e.kind.level.name(), " ", e.kind.target, " ", e.kind.name;
    if e.phase == trace.Phase.Begin {print <- " begins #", e.span;}
    if e.phase == trace.Phase.End {print <- " ends #", e.span;}
    var i = 0usize;
    while i < e.values.len {
      print <- " ", e.kind.names[i], "=";
      match e.values[i] {
        case let U64(v) {print <- v;}
        case let I64(v) {print <- v;}
        case let Text(v) {print <- v;}
        case let Duration(v) {print <- v, "ns";}
        else {print <- "?";}
      }
      i = i + 1usize;
    }
    if e.message.len > 0usize {print <- ": ", e.message;}
    print <- "\n";
  }
}

fn main() {
  trace.setLevel("fetcher", Level.Info);      // the program's choice, before the sink
  trace.install(Uni[Console](Level.Trace));    // CONE_TRACE, if set, replaces it
  fetch("https://example.com/a", 200);
  fetch("https://example.com/b", 404);
  trace.setLevel("fetcher", Level.Debug);
  fetch("https://example.com/c", 200);
}

It prints:

info fetcher request begins #1 url=https://example.com/a
info fetcher request ends #1
info fetcher request begins #2 url=https://example.com/b
warn fetcher refused status=404: the server said 404
info fetcher request ends #2
info fetcher request begins #3 url=https://example.com/c
debug fetcher fetched bytes=5120 took=830000ns
info fetcher request ends #3

The first fetch's fetched event is a Debug event of a target at Info, so it is off, and its arguments were never evaluated. Run with CONE_TRACE=fetcher=warn, the same program prints only the refused line until it sets the target to Debug itself.

Declaring kinds

A kind is what is known of an event before it happens: its name, its target (the package or subsystem it belongs to, such as "actors" or "httpclient"), its level, and the names and types of its fields. An event then carries only values. A kind of n fields is a Kindn, from Kind0 to Kind4, whose type arguments are its fields' types; make takes the name, the target, the level and the fields' names.

A kind is a global of the module that emits it, made in that module's initializer, and never moved afterwards: the facade keeps its address from its first event on. A field's type is one of seven, and a kind of any other is refused where it is made:

Field typeA value of it
i64, u64, f64, boola number or a truth value; a narrower number is widened where it is emitted
&stra text, borrowed for the event only: a sink that keeps it copies it
trace.Nanosa duration in nanoseconds (a time.Duration's nanos())
trace.Ticksa time of the facade's clock, trace.ticks()

The levels are Error, Warn, Info, Debug and Trace, from the least detailed to the most, and Off, which no event has and which wants none.

Emitting

A kind has four macro methods, each taking one argument for each field, in order:

UseWhat it records
k.emit(a, b)an event
k.log(a, b, msg)an event with a message: a text, or a trace.Message built in place with <- and no allocation (texts, integers and truth values, up to 240 bytes), written in parentheses as an argument
k.begin(a, b)the start of an interval, answering its id, or 0 when the kind is off
k.end(id)the interval's end; an id of 0 records nothing

Each is a macro, so that its arguments are put inside its test of whether the kind is on: when it is off, none of them is evaluated, so an argument may be as costly as it likes. When it is on, each is evaluated once, left to right, and checked against the field's type as a function's argument is. An interval holds nothing on the stack or in the thread: its end needs only its id, so it may come after an await, on another worker, or from another actor.

Each event records the place it was emitted (srcFile() and srcLine() of the macro's use), the time, read once from the clock, and a context: the worker running and the cause it runs for, from a provider a runtime registers with trace.setContextProvider, or noWorker and 0 with none.

Turning it on

Nothing is recorded until a program installs a sink, once, with trace.install(sink), or two with trace.installPair(first, second) (a file and the console, say), each of which records only the kinds it said it wanted. A sink is a struct declaring is trace.Sink, with three methods: enabled(k), whether it wants a kind's events, asked when the kind's state is worked out rather than per event; record(e), given each event of a kind it wanted, on the thread that made it; and flush(), asked by trace.flush() and when the program ends. A sink whose answer to enabled changes calls trace.refresh().

A kind is on when a sink is installed and wants it, and its level is no more detailed than its target's. A target's level is the one trace.setLevel(target, level) gave it, else the default, trace.setDefaultLevel(level), which starts as Off. Either may be changed while the program runs; trace.levelOf(target) answers the level now.

CONE_TRACE

When the sink is installed, the CONE_TRACE environment variable, if it is set, replaces whatever levels the program set before, so a program sets its own defaults first and installs second. trace.filter(spec) applies the same text from code. A spec is a list of directives separated by commas:

DirectiveMeans
infothe default level, for every target not named
httpclient=debugthat target's level
h3that target at Trace: everything

So CONE_TRACE=warn,httpclient=debug,actors=info wants warnings and errors from everything, and more from two targets. A level is named in any case; a target, up to 32 bytes, as it is spelled; spaces around either are ignored; a later directive for a target replaces an earlier one. A directive that is none of these (an unknown level, an empty or too long target, a thirty-third target) is skipped, and filter answers how many were.

What it costs

A kind keeps, in one byte, which sinks want it, worked out when it is first emitted and whenever a level, the filter or the sinks change. An event of a kind that is off costs a relaxed load of that byte and a compare. An event that is on reads the clock and the context once, and calls each sink that wants it.
