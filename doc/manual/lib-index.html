Before You Write It, It Exists

Most loops a program writes by hand, an insertion sort, a median, a search for the least, already have a name in the library. This page is an index of those ready-made operations, by what you were about to write. Each points to the page that says exactly what it does. If a loop you are about to write is not here, it may still be in the packages: look there before writing it.

What to keep writing by hand

A counting or bucket sort that builds an index of positions in O(n), the top two or four of a hot loop kept in a few slots, and a comparison that is an exact geometric test are better written where they are used. The library's sorts are for the general case.
