Cone
The Guide

This part is a guide to the pieces of Cone you will find in almost any program: values and text, decisions and loops, functions, your own structs and enums, the collections that hold your data, and actors that divide the work and run it on every core. It is written for a programmer meeting Cone for the first time, who may well know another language or two. Wherever Cone does a familiar thing, the Guide shows how it looks in Cone; wherever Cone does something of its own, it stops to say what and why.

It is complete enough that, by its end, you can write real programs that do interesting things. What it leaves out is the plumbing: how references and regions manage memory, how to build your own concurrency, how to make code generic and reusable, and how Cone meets C. Each of those has a part of its own after the Guide, for when you want to go a layer deeper.

Cone is a substantive language, so the Guide is not short. Read it in order: each page uses what the pages before it showed.

How to read a page

Every page has the same four layers, in the same order, so you can go as deep as you like and no deeper.

  1. A program. Each page opens with one complete program that shows what the page is about, followed by a few lines on what to notice in it. The same program is the page's lesson in the playground, where you can run it and change it with nothing installed. If the program makes sense to you, you may turn straight to the next page.
  2. The highlights. A short explanation of what the program shows, and why Cone does it that way.
  3. In detail. The complete rules for the page's topics: every form, every edge case, and notes on what is not built yet. Read it when something in the program puzzles you, or come back to it later as a reference. A first reading can skip it.
  4. Comes back in … Where the topic continues: a later page of the Guide, or a deeper part of the manual.

The pages

  1. A first program. Hello, line by line: mod, import, main and printing; building and running it with Congo.
  2. Values, variables and expressions. Numbers and their types, imm and mut, constants, operators, blocks that give a value, and which values copy and which move.
  3. Text. String literals, the methods of str, and String, text that grows.
  4. Deciding: if and match. Choosing between paths, with numeric examples.
  5. Repeating: while and each. while, each over a range, break and continue, and loops that give a value.
  6. Functions, closures and Result. Functions and closures, Result for what can fail, and generators: functions that yield values for each to walk.
  7. Structs and methods. Data of your own, with the methods that work on it.
  8. Enums, and match on variants. A value that is one of several variants, and taking it apart with match.
  9. Collections and the stream operator. Lists, dictionaries and sets; walking them with each; the stream operator; and where a collection's memory lives.
  10. Actors. Dividing the work among actors that send each other messages and await replies.
  11. parallel each. One loop run on every core, and where to go next.

Where it goes from here

After the Guide, each part takes one subject in depth, from what is used most to what you can build yourself: Memory, Concurrency, Modularity and reuse, Safety and the boundary with C, and the standard library and syntax reference.
