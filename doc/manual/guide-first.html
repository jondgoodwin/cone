A first program

The smallest useful program prints something, so that is where we begin: a program that greets the world in three languages and then does a little arithmetic.

// A first program
//
// Every Cone file names its module, 'import' brings in names from a package,
// and a program starts running at 'main'.

mod first;

import stdio use *;

fn main() {
  print <- "Hello, world!\n";
  print <- "Bonjour, le monde!\n";
  print <- "こんにちは 世界!\n";

  // print takes numbers too, and any mix of values, separated by commas
  print <- "Six times seven is ", 6 * 7, "\n";
  print <- "A day has ", 24 * 60 * 60, " seconds\n";
  print <- "Pi is about ", 355d / 113d, "\n";
}

It prints:

Hello, world!
Bonjour, le monde!
こんにちは 世界!
Six times seven is 42
A day has 86400 seconds
Pi is about 3.14159

What to notice

  • // begins a comment, which runs to the end of the line.
  • mod first; names the module this file makes. A Cone file starts by naming its module; leave the line out and the compiler refuses the file, asking for it.
  • import stdio use *; brings in the standard input and output names, print among them. Imports come right after the mod line.
  • fn main() { ... } declares the function the program starts running at. Its statements, between the braces, run in order.
  • print <- a, b, c; sends each value, in order, to the output. <- is the stream operator, which comes back for collections. \n in a string is the end of a line. Strings are UTF-8, so text in any language prints just as it is written.
  • Every statement that does not end with a block ends with a semicolon (Statements).

The shape of a Cone program

If you have written C, Go or Java, most of this program will look familiar. Code lives in functions, a function's body sits between braces, statements end with semicolons, and the program begins at a function called main. Comments are written //, as they are in all of those languages.

Two lines come before any code. The first, mod first;, says which module the file is. A module is Cone's unit of code: a file, or a folder of files, whose names belong together. The second, import stdio use *;, brings in another module's names, here the standard library's printing, so that print can be written on its own. That is all a program needs to know about modules for the whole of this Guide; the Modularity part has the rest.

Printing with the stream operator

The line that does the work may be the least familiar. There is no printf and no format string: print is an output stream, and the arrow <- sends values into it. Each value after the arrow goes out in turn, so a message is just the pieces of it, in order, separated by commas. Text goes out as it is written, and a number is turned into its digits for you. The expression 6 * 7 is worked out first, and its value, 42, is what is printed.

The same arrow has one meaning wherever it appears: put these values into that. The Text page uses it to build up a string piece by piece, exactly as here, and the Collections page to add items to a list. Learn it once here, and you will keep meeting it.

The last line divides two numbers written with a d after them. That letter makes each a 64-bit floating-point number, so the division keeps its fraction. Without it, 355 / 113 would be a division of whole numbers, and print 3. Numbers and their types are the subject of the next page.

Running it

Save the program as first.cone and run it with Cone's build tool, Congo:

congo run first.cone

Congo compiles the program and the packages it imports, links them, and runs the result. Or paste the program into the playground, which runs it in the browser with nothing installed.

Building and running it

The build tool, Congo, builds and runs programs. A single file with no manifest is run with congo run and its name:

congo run hello.cone

A program bigger than one file is a package: a folder holding a manifest, congo.toml, and the source under src, whose root module's file is named for the package. congo new hello makes one; congo run, from anywhere inside it, builds it and runs it; congo build only builds, and --release optimises:

> congo new hello

> cd hello
> congo run

   Compiling core v0.1.0 (C:\src\cone\packages\core)
   Compiling stdio v0.1.0 (C:\src\cone\packages\stdio)
   Compiling hello v0.1.0 (C:\work\hello)
     Linking build\debug\hello.exe
    Finished debug build\debug\hello.exe
     Running build\debug\hello.exe
Hello, world!

hello/
    congo.toml
    src/hello.cone
    tests/

Congo finds each package a program imports by its name, compiles each one on its own with the Cone compiler, conec, and links them; what a build writes goes in the package's build/debug folder (build/release for --release). Arguments after -- go to the program: congo run -- a b. congo test runs a package's tests (Testing).

The playground runs a program in the browser with nothing installed. Packages and Congo has the manifest, C packages and the build in full.

A second program: pi

To keep it simple, we focus first on how to read and write programs that work with numbers, such as this one which calculates the value of pi:

// Calculate and print the value of pi
//
// Numbers, mutable variables, and a 'while' loop.

mod pi;

import stdio use *;

fn main() {
  print <- "π=", calcpi(10), "\n"; // <-- Change 10 to 2 for less accurate pi
}

// Calculate pi using the arc-sine fractional sequence.
// 'nterms' is the number of fractional terms used to estimate pi
// https://en.wikipedia.org/wiki/Approximations_of_%CF%80#Arcsine
// A parameter is immutable unless marked 'mut'; '= 10' is its default value.
fn calcpi(mut nterms = 10) f64 {
  if nterms <= 0 {
    return 0d;
  }

  // Initialize working values
  mut result = 0.5d;
  mut seed = 1d;
  mut top = 1d;
  mut bot = 1d;
  mut twos = 2d;
  mut term = 0d;

  while --nterms {
    // Calc a new fraction and add to result
    top *= seed;
    bot *= seed + 1d;
    twos *= 2d * 2d;
    term = top / (bot * (seed + 2d) * twos);
    result += term;
    seed += 2d;
  }
  // The last expression of a function is its result
  result * 6d;
}

It prints π=3.14159.

Where the Guide goes from here

Over the next few pages, the story will unfold in this way: We begin by introducing the primitive values: numbers and variables. Using these values and various operators, we can then form expressions that calculate new values. Multiple expressions and other statements can then be assembled into a block, which evaluates its statements in order (Values, variables and expressions). Text comes next (Text). The if and while in calcpi follow (Conditionals and Loops), then the functions that hold a program's logic (Functions), and then the data a program defines for itself (Structs and methods).
