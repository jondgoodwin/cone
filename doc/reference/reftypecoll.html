Collection Types

Note: The library collection types are the collections package's List[T] and Dict[K, V] (keyed by String only), with String beside them (import collections use *;). A list or a dictionary is constructed with new, its first values after <-: new List[i32](100) <- fill 0 (a collection's contents). Each holds its elements in one block it gets from the C allocator through a raw pointer, not in an array reference. A borrow of an element (list[i], dict[key], s.view()) keeps a local collection loaned while it is used: it may be read, but a push, which may move every element, waits for the borrow's last use (see borrowed references). A mutable borrow (&mut list[i], or list.viewMut(), a &[]mut T of every element, and a String's s.viewMut() of its bytes) keeps it loaned entirely: until its last use the collection may be neither read nor changed any other way. Each declares ShapeChanging (a provisional name), which is to refuse such a borrow through a shared path, a &mut List parameter say; that check is not built, and a push through another reference to the same collection leaves the borrow dangling. A list that a C function fills (the "ask how many, then fill" shape of Vulkan's queries) needs no unsafe code: list.resize(n, zero) makes it n copies of a value long (or drops the values past n), the C function is handed list.viewMut(), and list.truncate(written) cuts it to the count C wrote, finalizing the values it drops (a no-op when written is not less than its length). resize exists only where T copies; a list of values with finalizers is shortened with truncate. The array primitives are implemented as far as the next two pages say.

A collection type holds some number of values (elements) that are all the same type. The standard library offers a number of versatile collection types, such as List and Dict.

All such collection types are built on top of the array primitive types, whose elements are co-located in memory and are individually accessed using an integer index:

  • Array types. An array has a statically known size.
  • Array reference types. An array reference, a slice, is a borrowed view of some runtime-determined number of elements of the same type: all or some of the elements of an array, or of a collection. It owns none of them. An array whose length is chosen at runtime is a collection.
