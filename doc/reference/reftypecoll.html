Collection Types

Note: The library collection types are the collections package's List[T] and Dict[K, V] (keyed by any type that is Hash), with String beside them (import collections use *;). A list or a dictionary is constructed with new, its first values after <-: new List[i32](100) <- fill 0 (a collection's contents). Each holds its elements in one block it gets from the C allocator through a raw pointer, not in an array reference. A borrow of an element (list[i], dict[key], s.view()) keeps a local collection loaned while it is used: it may be read, but a push, which may move every element, waits for the borrow's last use (see borrowed references). A mutable borrow (&mut list[i], or list.viewMut(), a &[]mut T of every element, and a String's s.viewMut() of its bytes) keeps it loaned entirely: until its last use the collection may be neither read nor changed any other way. Each declares ShapeChanging (a provisional name), which is to refuse such a borrow through a shared path, a &mut List parameter say; that check is not built, and a push through another reference to the same collection leaves the borrow dangling. A list that a C function fills (the "ask how many, then fill" shape of Vulkan's queries) needs no unsafe code: list.resize(n, zero) makes it n copies of a value long (or drops the values past n), the C function is handed list.viewMut(), and list.truncate(written) cuts it to the count C wrote, finalizing the values it drops (a no-op when written is not less than its length). resize exists only where T copies; a list of values with finalizers is shortened with truncate. The array primitives are implemented as far as the next two pages say.

Note: Dict[K, V] is a SwissTable: an open-addressed table with a control byte for each bucket (empty, removed, or the top 7 bits of the key's hash), read eight at a time as one 64-bit word, so a lookup compares a key only in a bucket whose tag matches; it holds up to 7/8 of its buckets, and doubles when full. Its keys are any type that is Hash: integers and bool, a String, a pool.Ref[T], a struct that declares is Hash (the compiler supplies its hash from its fields); a float key is refused. A key moves in and the dictionary owns it. It is unordered: each dictionary keeps a seed of its own, the process's random one by default, so keys(), values() and entries() (cursors, each next() giving an Option of a borrow, the dictionary loaned while one is used) visit in a different order on every run, and a program sorts, or looks a key up, rather than rely on it. Dict[K, V].deterministic() fixes the seed, and then the same keys inserted in the same order are visited in the same order on every run; Dict[K, V].withSeed(n) takes one of your own. Lookups take a &K: get(&k) is an Option of a borrow of the value, getMut a mutable one, getCopy an Option of a copy (only where the value copies, which is the lookup that works through a shared Rc[mut, Dict[K, V]]), contains, remove (the value moved out, the key finalized), d[&k] and &mut d[&k] (a panic for a key it does not hold), insert(k, v) (true when it replaced an entry, finalizing the old key and value), getOrInsert(k, v) (a mutable borrow of the value held, or else v moved in, with one search: *counts.getOrInsert(word, 0) += 1), clear, len and capacity (the entries it holds before it grows). A Dict[String, V] also takes the key as bytes, a &[]u8 (d.contains("core")), for every one of these lookups.

A collection type holds some number of values (elements) that are all the same type. The standard library offers a number of versatile collection types, such as List and Dict.

All such collection types are built on top of the array primitive types, whose elements are co-located in memory and are individually accessed using an integer index:

  • Array types. An array has a statically known size.
  • Array reference types. An array reference, a slice, is a borrowed view of some runtime-determined number of elements of the same type: all or some of the elements of an array, or of a collection. It owns none of them. An array whose length is chosen at runtime is a collection.
