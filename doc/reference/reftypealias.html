typedef

To create a named alias for some type, use typedef in the appropriate module's global scope (it may not be placed anywhere else):

typedef Noderef &rc mut Node;

In this example, wherever Noderef is used in this module, it will be understood to mean &rc mut Node.

A typedef is a second spelling for one type, not a second type: it creates no distinct type and nothing is asserted by using one name rather than the other. To declare a type of your own that enriches an existing one with methods, which is a distinct type, see Enriching a concrete type.

Because it is a second spelling and not a second thing, it also qualifies what it names. Where typedef Sample Reading names a struct, Sample.make(1) reaches the same static function Reading.make(1) does.

A typedef may be declared pub, which makes the name visible outside its module; the type it names keeps its own visibility, so an alias never lends out something private. A chain of aliases is ordinary — one typedef may name another — but a chain that comes back to itself names no type at all, and is refused where it is written.
