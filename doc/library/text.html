Text, formats and data

Text, character data, encodings and file formats.

Text

  • unicode [Windows and Linux]: Character properties, case mapping, full case folding, NFC/NFD normalization, grapheme clusters and the regex word, digit and space classes from the Unicode Character Database.
  • format [Windows and Linux]: Options for one number in a text, as small typed values that are themselves writable.
  • regex [Windows and Linux]: Regular expressions compiled to a byte-level automaton, with Unicode word, digit and space classes.
  • textdiff [Windows and Linux]: The differences between two texts, line by line, and the unified diff.

Editing and documents

  • textedit [Windows and Linux]: An editing core for text and code (a piece table), its undo commands and a code editor widget.
  • richtext [Windows and Linux]: Documents with paragraphs, styles, lists and images, and their editor.

Data formats and encodings

  • json [Windows and Linux]: JSON (RFC 8259) read and written: a value tree, a streaming reader, and accessors.
  • toml [Windows and Linux]: A reader for a subset of TOML, enough for Congo's manifests.
  • binarytext [Windows and Linux]: Bytes as text: Base64 and hex, one-shot and streaming.
  • textcodec [Windows and Linux]: UTF-16 (both byte orders, byte-order marks), Latin-1 and Windows-1252 to and from UTF-8, in Cone.
  • uuid [Windows and Linux]: UUIDs (RFC 9562): random v4, time-ordered v7, parse and print.
  • cryptohash [Windows and Linux]: SHA-256, SHA-512, SHA-1, SHA-3 and MD5 (not for security), HMAC, constant-time comparison, PBKDF2 and HKDF.
  • imagedecode [Windows and Linux]: PNG and JPEG decoders and a PNG writer, with no C library.
  • csv [Windows and Linux]: CSV (RFC 4180) read and written as text, in Cone, with no C library.
