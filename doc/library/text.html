Text, formats and data

Text, character data, encodings and file formats.

Text

  • unicode: Character properties and simple case mapping from the Unicode Character Database.
  • format: Options for one number in a text, as small typed values that are themselves writable.
  • regex: Regular expressions compiled to a byte-level automaton.
  • textdiff: The differences between two texts, line by line, and the unified diff.

Editing and documents

  • textedit: An editing core for text and code (a piece table), its undo commands and a code editor widget.
  • richtext: Documents with paragraphs, styles, lists and images, and their editor.

Data formats and encodings

  • json: JSON (RFC 8259) read and written: a value tree, a streaming reader, and accessors.
  • toml: A reader for a subset of TOML, enough for Congo's manifests.
  • binarytext: Bytes as text: Base64 and hex, one-shot and streaming.
  • cryptohash: SHA-256, SHA-512 and SHA-1, HMAC, constant-time comparison, PBKDF2 and HKDF.
  • imagedecode: PNG and JPEG decoders and a PNG writer, with no C library.
