The Cone library

Core and the basics

The prelude and runtime, the operating system, time, numbers, threads and actors.

The prelude and the runtime

  • core: The prelude: loaded before any module and wildcard-imported into every module.
  • conestd: The runtime every native Cone program links beside its own objects: panics, traced roots, printing, raw blocks.
  • stdio: Printing to standard output and standard error.
  • libc: Raw bindings to the ISO C standard library.
  • posix: Raw bindings to the POSIX functions beyond the C library: files, directories, processes, environment.

The program and its machine

  • env: The process's environment: its arguments and environment variables, read, set and removed.
  • args: A small lexer for a program's command line: options and other arguments, one at a time.
  • process: Run another program and wait for it with its output captured; this program's own arguments and path.

Time and numbers

  • time: Time values: Duration, Instant, Timestamp and Clock.
  • calendar: The civil calendar over Timestamp: dates, times of day, RFC 3339 and HTTP dates.
  • zonedata: Where a calendar Zone comes from on this machine, by IANA name or the machine's own.
  • random: A seeded, repeatable pseudo-random generator and what is drawn from it.
  • bigint: Arbitrary-size integers, BigUint and BigInt, written in Cone with no C.

Threads and actors

  • thread: Operating-system threads, a deliberately small layer.
  • sync: What threads share safely: Arc, the futex, Mutex, Rwlock, Condvar and Once.
  • actors: The runtime Cone's actors run on: mailboxes, behaviours and worker threads.
  • cancelgroups: The one carrier of "stop this work" for all of Cone's concurrency.
