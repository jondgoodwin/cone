The Cone library: packages by domain

The library

Every package in packages/, grouped by the domain it serves. Each domain page lists its packages in subgroups, one line each; a package appears on exactly one domain page (tools/library/check_catalogue.py checks it). Detailed descriptions come later.

  • 3D (70 packages): Shapes, meshes, animation, physics, rendering, XR, worlds and interfaces for three-dimensional programs.
  • Regions and collections (9 packages): Where values live and how they are kept: homogeneous collections and pools, and the regions that hold many kinds.
  • Core and the basics (17 packages): The prelude and runtime, the operating system, time, numbers, threads and actors.
  • Networking and streaming (29 packages): Streams first, then what is streamed: the asynchronous I/O runtime, HTTP, files, archives, compression and messages.
  • Audio and voice (8 packages): Mixing and playing sound, and speaking with a local model.
  • AI and language models (7 packages): Running and talking to language models.
  • Text, formats and data (11 packages): Text, character data, encodings and file formats.
  • Tools and testing (12 packages): What builds, checks, observes and demonstrates the language and its packages.
