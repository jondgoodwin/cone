Tools and testing

What builds, checks, observes and demonstrates the language and its packages.

Testing and observing

  • testing: Checks for a package's tests, run by congo test.
  • trace: The facade every package logs and traces through: kinds of event declared once, emitted through macros.
  • logsink: A console sink for trace: events written as one text line on standard output.
  • actortrace: Tracing the actors runtime, a first round: three ways of recording the same events.

The compiler's own libraries

  • llvmc: LLVM's C API declared by hand, groundwork for a code generator written in Cone.

Samples of language features

  • actortraitlib: Sample: an actor trait that other packages' actors conform to.
  • closurelib: Sample: closures written in bodies other packages use.
  • genwalk: Sample: generators that other packages walk.
  • genuser: Sample: generators that hand on to another package's generators.
  • gpupart: Sample: a program package with a gpu/ folder, a part in two halves.
  • gpusample: Sample: a package of Cone kernels marked for the GPU, compiled for both CPU and GPU.
  • meshedpart: Sample: a part sampled and meshed on the GPU, end to end.
