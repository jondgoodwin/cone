LLVM (linked into conec)
    conec contains the LLVM libraries (the X86, WebAssembly and SPIR-V code
    generators, the optimizer and the support libraries), so LLVM's licence
    travels with it: the Apache License 2.0 with LLVM Exceptions.
    licenses/LICENSE-LLVM-Apache-2.0-with-LLVM-exception.txt (the text of the
    LICENSE.TXT of LLVM's source tree). https://llvm.org/LICENSE.txt

Python (Windows archive only: python/)
    Python's embeddable distribution, unmodified, runs Congo. Python Software
    Foundation licence: licenses/LICENSE-Python-PSF.txt (also python/LICENSE.txt).
    https://www.python.org/

SDL3 (Windows archive only: packages/sdl/clib/)
    SDL3.dll and SDL3.lib, the prebuilt files of SDL3's development kit,
    unmodified. zlib licence: licenses/LICENSE-SDL3-zlib.txt.
    https://libsdl.org/

OpenSSL (Windows archive only: packages/tls/clib/)
    libssl-3.dll, libcrypto-3.dll and their import libraries, the builds that
    CPython's own binary dependencies repository publishes (OpenSSL 3.5.9, signed
    by the Python Software Foundation), unmodified. Apache License 2.0:
    licenses/LICENSE-OpenSSL-Apache-2.0.txt. https://www.openssl.org/

On Linux the tls package uses the system's OpenSSL (libssl-dev) and nothing else
is bundled from outside the Cone repository except LLVM, linked into conec.

The executables in this archive are not code-signed.
