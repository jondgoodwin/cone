Two ways to use Cone: build code with the compiler, or run the 3D browser. Every file here was built from one commit of the Cone repository (@HASH8@), so the compiler, the packages, the reference manual and the playground agree.

Build code: the Cone compiler

The compiler (conec), Congo (the build tool), and every Cone package, the standard library and the 3-D libraries included, so nothing is fetched afterwards.

Windows (64-bit)

irm https://cone.jondgoodwin.com/install.ps1 | iex

The script downloads the zip below, checks its SHA-256, unpacks it into %LOCALAPPDATA%\Cone and puts it on your user PATH. It needs no administrator rights. Python is included (Congo runs on Microsoft's embeddable Python), so there is nothing to install for that.

File@WIN_FILE@ (@WIN_SIZE@)
SHA-256@WIN_SHA256@

You need Windows 10 or 11 and Microsoft's C++ Build Tools (Build Tools for Visual Studio 2022, workload "Desktop development with C++"), because Congo links programs with Microsoft's linker. The installer checks for them and prints how to get them if they are missing.

Linux (x86-64)

curl -fsSL https://cone.jondgoodwin.com/install.sh | sh

The script downloads the tarball below, checks its SHA-256, unpacks it into ~/.local/share/cone and links conec and congo into ~/.local/bin. No root needed.

File@LINUX_FILE@ (@LINUX_SIZE@)
SHA-256@LINUX_SHA256@

You need Ubuntu 24.04 (the tested system) or another distribution with glibc 2.38 or later, and these from your package manager (the archive carries none of them):

sudo apt install build-essential python3

Python must be 3.11 or later. Programs that use the tls package also need sudo apt install libssl-dev. The packages that draw a window (sdl and what is built on it) are Windows-only for now.

First program

congo new hello
cd hello
congo run

Run the 3D browser

@BROWSER_ENTRY@

Check what you downloaded

The scripts above check for you. To check a file by hand, compare its SHA-256 with the value on this page (or in SHA256SUMS):

Get-FileHash -Algorithm SHA256 @WIN_FILE@        (PowerShell)
sha256sum @LINUX_FILE@        (Linux)

The executables are not code-signed. Windows may show its "unrecognised app" warning the first time conec.exe runs; choose "More info", then "Run anyway", if you trust the file.
