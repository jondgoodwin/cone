The compiler (conec), the Congo build tool and every Cone package, in one install.

@WINDOWS_COMPILER@

Linux (x86-64)

curl -fsSL https://cone.jondgoodwin.com/install.sh | sh

Needs glibc 2.38 or later (tested on Ubuntu 24.04), Python 3.11 or later, and:

sudo apt install build-essential python3 git

First program

congo new hello
cd hello
congo run
